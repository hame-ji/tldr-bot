Title: Notion AI Agent Orchestration and External API

TL;DR: Notion is introducing a unified orchestration UI and an External Agent API to integrate, manage, and automate multiple third-party and custom in-house AI agents within shared workspaces.

Key points:
- Notion is positioning its workspace as a unified interface layer to solve the friction of juggling multiple specialized AI tools across disjointed terminal tabs and environments.
- Users will be able to tag and interact with partnered AI agents directly within Notion task threads and documents, functioning similarly to human collaborators.
- A new External Agent API is in development, allowing engineering teams to wrap their proprietary, internally built AI agents and surface them directly within the platform.
- Task boards can be configured for automated, multi-agent workflows, piping tasks through different specialized agents sequentially before automatically assigning them for human review.

Why it matters:
- Centralizing agent orchestration within existing team knowledge bases minimizes context switching and allows engineering teams to scale automated workflows directly where their project specifications and tasks already live.

Evidence:
- Announced launch partners for direct integration include Claude, Codex, Cursor, Decagon, and Amplitude.
- The features will initially roll out for coding agents, with the External Agent API and remaining partnerships launching in the coming months.

Caveat:
- The information is sourced directly from a vendor feature presentation, meaning technical specifications, API limitations, and real-world integration friction remain undisclosed.
